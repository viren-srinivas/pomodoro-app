# Pomodoro App

A modern Pomodoro timer application that helps you stay focused and motivated during your work sessions. The app features:

- Customizable Pomodoro timer with work and break sessions
- Clean, modern UI with Tailwind CSS
- Session tracking
- Progress monitoring

## Features

- **Pomodoro Timer**: Standard 25/5 minute work/break cycles
- **Session Management**: Track your work and break sessions
- **Modern UI**: Built with React, TypeScript, and Tailwind CSS
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Local Storage for data persistence

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. The app will be available at `http://localhost:5173`

## Development

The app is built with:
- Vite for fast development and building
- React for UI components
- TypeScript for type safety
- Tailwind CSS for styling
